# PizzaMaker

FoodMaker 저장소의 `PizzaMaker` 브랜치에서 main과 독립적으로 개발하는 피자 만들기 게임입니다.

## 현재 버전
- v0.3.0
- 실제 일러스트 에셋 기반 렌더링\n- 재료 투입 즉시 시각 변화, 그릇/오븐 전후 레이어 분리\n- 소스/치즈가 손가락 경로를 따라 실제 위치에 누적\n- 자르기/먹기/완성까지 사용자가 올린 토핑 유지\n- 완료 후 숨은 좌표 조건 없이 자동 단계 전환
- GitHub Actions Debug APK 빌드 성공

## 아트 시스템
- 사용자가 제공한 크레용/색연필 피자 에셋을 기준으로 새로 제작한 이미지 자산 사용
- 주방 배경, 오븐 열림/닫힘, 그릇, 밀대, 숟가락, 소스 국자, 치즈통, 피자커터, 접시 등 실제 이미지 에셋 사용
- 도우/소스/치즈/구운 피자/절단 피자 상태별 이미지 사용
- 페퍼로니, 버섯, 피망, 올리브, 양파 및 추가 재료 이미지 포함
- 효과 이미지 포함
- 음식/도구/배경을 Canvas 도형으로 생성하던 이전 방식 제거
- Canvas는 버튼, 텍스트, 진행바, 터치 가이드 등 동적 UI에만 사용

에셋 팩은 저장소의 `app/src/main/assetpack/part*.b64`에 분할 보관되고 빌드 시 원본 ZIP으로 무손상 복원되어 APK의 `assets/pizzamaker_assets.zip`에 포함됩니다.

## 플레이 루프
1. 밀가루, 물, 오일을 그릇에 직접 드래그
2. 숟가락으로 반죽 섞기
3. 밀대로 반죽 펴기
4. 토마토 소스 바르기
5. 치즈 뿌리기
6. 페퍼로니, 버섯, 피망, 올리브, 양파 자유 배치
7. 피자를 직접 오븐에 넣고 굽기
8. 피자커터로 세 방향 자르기
9. 여섯 조각을 눌러 먹기
10. 완성 연출 후 다시 만들기

## 개발 원칙
- main 브랜치와 독립
- 외부 게임의 이미지, 코드, 사운드 복제 사용 안 함
- 버튼 중심 UI보다 드래그, 문지르기, 회전, 자르기 중심
- 어린이 사용을 가정해 넓은 판정과 실패 없는 흐름 유지
- placeholder 그래픽 대신 실제 게임용 일러스트 에셋 사용
